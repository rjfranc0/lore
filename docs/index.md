# lore

A Rust CLI that manages AI agent skills and behaviors via symlinks into a
single universal directory (`~/.agents/`), and wires that directory into
one or more Claude accounts (`~/.claude/`, `~/.claude-<account>/`).

## Start here

- [functional/index.md](functional/index.md) — what lore does and why,
  from the user's perspective.
- [implementation/index.md](implementation/index.md) — how the code is
  structured to deliver that behavior.
- [infra/index.md](infra/index.md) — how a commit becomes a released,

## Core idea

Everything lore manages is either a symlink or one of three generated files
(`AGENTS.md`, `LORE.md`, `CLAUDE.md`) — though `CLAUDE.md` is special:
lore only ever owns a single import line inside it, never the whole file,
so it can coexist with other tools that write their own lines there.
Nothing is ever copied, and removing/uninstalling never modifies a skill or
behavior's source repo — only the symlink lore created. See
[functional/agent-config/index.md](functional/agent-config/index.md) and
[functional/accounts.md](functional/accounts.md) for the full model.

## Project facts

- Single binary (`lore`), built from a single library crate —
  `src/main.rs` is a one-expression entry point (`lore::run()`) into
  [implementation/cli.md](implementation/cli.md).
- No `design/` or `data/` domain exists in this tree: lore has no
  UI/visual layer, and its two on-disk formats (`lore.toml`, `AGENTS.md`'s
  block format) are simple enough to live as module contracts inside
  [implementation/accounts/index.md](implementation/accounts/index.md) and
  [implementation/agent-config.md](implementation/agent-config.md) rather
  than warranting a dedicated `data/` domain.

This tree was generated by reading the full `src/`, `tests/integration/`,
and CI/release configuration directly — no prior corpus-generated docs
existed. A separate hand-maintained file, `docs/reference.md`, predated
this tree and documented the pre-`lore.toml` `AGENTS_DIR`/`CLAUDE_DIR` env
vars plus a `bats` test suite that no longer exists in this repo (tests
are the Rust integration suite under `tests/integration/`). It was retired
during the first Audit/Rewrite pass — its accurate content was already
superseded by [functional/agent-config/index.md](functional/agent-config/index.md)
and [functional/accounts.md](functional/accounts.md).
